# Scientist Constraints

## Benchmark Inputs

Use the deterministic inputs generated by `data/attention_inputs.py` with the default chunk, frame, token, dimension, and seed settings. Changing these settings can make the task easier or harder without improving the sparse attention method.

## Evaluation Interface

Submit methods by writing the same artifact format consumed by `scripts/evaluate.sh`: per-chunk output tensors plus active and total block counts. Do not modify `eval/` when reporting improved method scores.

## Cost Accounting

Report active blockwise attention tiles using the same block size and accounting convention. Dense fallback must be counted as dense; omitted accounting invalidates the efficiency constraint.

## Compliance Checklist

- [ ] Default deterministic benchmark settings are unchanged.
- [ ] `eval/` and `scripts/evaluate.sh` are unchanged for scored results.
- [ ] Output artifacts include real per-chunk tensors produced by the submitted method.
- [ ] Active and total block counts use the benchmark block definition.
